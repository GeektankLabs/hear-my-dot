HEAR MY DOT / LOCAL DIAGNOSTIC

What reaches Chrome?

This opt-in probe records extension command events, not raw headset gestures. It does not pause, play, mute, record audio, or change shortcuts.

1. Review bindings

All commands start unbound. In chrome://extensions/shortcuts, manually assign only the media key you intend to test. Keep its scope In Chrome. Test one binding at a time.

A test binding may take the key away from normal player control. Remove it after testing. An empty binding means unassigned or unavailable; Chrome does not tell this probe which app or extension owns a conflicting shortcut.

2. Press the real headset button

Keep Chrome focused. Try one press, then two quick presses, then a long press. Leave a few seconds between attempts. Describe the gesture yourself; the log only shows received commands and their arrival intervals.

No event is inconclusive: routing, binding conflicts, an unsupported headset signal, or the selected scope may be responsible. API support is not proof that your hardware sends that command.

No network or permanent storage. The page keeps up to 100 events while open; worker history can disappear when Chrome suspends it. Copy any observations before closing the page. Timestamps are receipt times, not physical press duration.

3. Finish

Clear all probe bindings in Chrome's shortcut settings, then remove this diagnostic extension. Your main Hear My Dot installation is unchanged.
